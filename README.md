# Daily Amar Desh Mobile App (আমার দেশ অ্যাপ)

> A mobile-responsive web application replicating the popular Bengali newspaper Daily Amar Desh (dailyamardesh.com)

## 📱 About

This is a mobile-first web application that brings the Daily Amar Desh newspaper experience to mobile devices. It features Bengali news categories, prayer times, article browsing, and more.

## 🚀 Features

- 📰 **Home Feed** - Latest news with hero article layout
- 📂 **Category Navigation** - Browse 20+ news categories
- 🔍 **Search** - Find articles by keyword
- 📖 **Article Reader** - Full article view with images
- 🕐 **Prayer Times** - Daily Salah times widget
- 🔖 **Bookmarks** - Save articles for later
- 🌙 **Dark Mode** - Toggle light/dark themes
- 📱 **Mobile Responsive** - Optimized for all screen sizes
- 🇧🇩 **Bengali UI** - Full বাংলা language support

## 🏃 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
